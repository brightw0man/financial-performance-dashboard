# Financial Performance Dashboard

## Project Overview

This project simulates the financial performance monitoring of an international manufacturing company.

The objective is to analyse financial performance by comparing:

- Actual results
- Budget
- Forecast

The analysis focuses on revenue, OPEX, CAPEX, EBITDA and financial variances.

## Business Objective

The purpose of this project is to provide management with a clear view of financial performance and identify the main drivers of budget variances.

## Tools

- Microsoft Excel
- Power BI
- DAX
- Financial Analysis

## Key KPIs

- Revenue
- EBITDA
- OPEX
- CAPEX
- Budget Variance
- Forecast Variance
- Variance %
